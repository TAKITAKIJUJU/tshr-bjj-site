`src/lib/booking-date.js` の判定をブラウザとCloudflare Workerで共有する。
標準の日付ピッカーでは曜日単位のグレーアウトができないため、休館日を入力すると
その場でエラーを表示し、フォームの送信をブロックする。日付を変更・削除すると解除する。

フォームのPOST先は `/contact/`。`docs/production/booking-form.js` が希望日を確認し、
不正なら422（形式を読めないリクエストは400）を返す。正しい希望日または空欄の場合は
307で既存のFormSubmit送信先へPOST本文を保持して引き継ぐ。既存の送信先、迷惑送信対策、
件名、完了画面は変更していない。Workerでは個人情報の記録やメール送信は行わない。

検証:

```powershell
node --test scripts/site/booking-date.test.mjs
node scripts/site/check.mjs
node scripts/site/validate.mjs
node scripts/site/verify-booking.mjs
node scripts/site/verify-live.mjs
```

日付判定・日本時間の日付境界・サーバー判定など29テストに合格。公開先でも日曜・火曜・
過去日を422で拒否し、土曜・希望日空欄は既存メールサービスへの307となることを確認。
